# 🌐 Tu IP Pública - Estilo Retro Vaporwave

Esta es una página web retro que te muestra tu IP pública junto con información detallada como país, ciudad, región, ISP, y ubicación aproximada. Además, incluye un mapa embebido de Google Maps y un generador de código QR de tu IP.

## 🧠 ¿Qué hace?

- Muestra tu IP pública en pantalla.
- Obtiene datos de geolocalización desde `ipapi.co`.
- Muestra un mapa con tu ubicación aproximada (OpenStreetMap + Leaflet).
- Embebe Google Maps centrado en tu ubicación.
- Genera un código QR con tu IP.
- Soporte para tema claro/oscuro.
- Animaciones sutiles con ScrollReveal.
- Interfaz con estética *Vaporwave/Retro Pixel* 🎮

## 💻 Tecnologías usadas

- HTML + CSS + JavaScript
- Leaflet.js (para el mapa interactivo)
- ScrollReveal (animaciones)
- ipapi.co API (para obtener IP y ubicación)
- Google Maps (embebido)
- QR Server API (para generar el código QR)

## ⚙️ Cómo usar

1. Clona este repositorio.
2. Abre `index.html` en tu navegador.
3. ¡Listo! Verás tu IP y ubicación con estilo retro.
